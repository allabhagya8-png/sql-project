# Job Portal Management System Using MySQL

## Project Description

The **Job Portal Management System Using MySQL** is a database-driven application designed to manage job vacancies, job seekers, employers, and job applications efficiently. The system uses MySQL to store, organize, retrieve, and manage recruitment-related information in a structured and reliable manner.

The project demonstrates essential database concepts, including relational table design, primary and foreign keys, SQL queries, joins, constraints, and data manipulation operations. It aims to simplify recruitment activities by maintaining organized records of job postings, candidate details, and application statuses.

## Objectives

- Design and implement a relational database for job portal operations.
- Store and manage job seeker and employer information.
- Maintain job vacancy details and application records.
- Retrieve relevant information using SQL queries.
- Establish relationships between tables using primary and foreign keys.
- Generate useful recruitment reports using joins and aggregate functions.

## Technologies Used

- **Database Management System:** MySQL
- **Query Language:** SQL
- **Database Tool:** MySQL Workbench (optional)

## Database Modules

### 1. Job Seeker Management
Stores candidate details, contact information, qualifications, skills, and resume references.

### 2. Employer Management
Maintains employer profiles, company details, and contact information.

### 3. Job Management
Stores job titles, descriptions, required skills, locations, salary details, and vacancy information.

### 4. Application Management
Records job applications, application dates, candidate details, and application statuses.

### 5. Reporting and Data Retrieval
Uses SQL queries to retrieve job listings, candidate applications, employer details, and application summaries.

## Key Database Concepts

- Database creation and table design
- Primary key and foreign key constraints
- INSERT, UPDATE, DELETE, and SELECT statements
- WHERE, ORDER BY, and GROUP BY clauses
- INNER JOIN and OUTER JOIN operations
- Aggregate functions such as COUNT, SUM, and AVG
- Data integrity and relational table relationships

## Expected Benefits

- Centralized storage of recruitment data.
- Efficient retrieval and updating of records.
- Reduced data duplication through appropriate database design.
- Improved consistency between related tables.
- Easier tracking of job applications and vacancies.

## Conclusion

The Job Portal Management System using MySQL demonstrates how relational databases can support recruitment operations. By organizing job seekers, employers, job postings, and applications into related tables, the project provides a structured approach to data storage, retrieval, and management while strengthening practical SQL and database design skills.
